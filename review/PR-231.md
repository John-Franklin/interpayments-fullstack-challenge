# PR #231: Daily settlement report

**Author:** Morgan (payments team) · **Base:** `main` · **Diff:** [`PR-231.diff`](./PR-231.diff)

Merchants keep asking support to reconcile their bank deposits against our
receipts, and right now that means someone exporting payments to a spreadsheet
by hand. This adds a daily settlement report merchants can pull up themselves.

### Changes

- New `GET /api/reports/settlement?date=YYYY-MM-DD`: gross, surcharge collected,
  refunds and net for the day, plus a breakdown by card network
- BFF route for it, cached for 5 minutes since it's the most expensive thing
  we ask the payments API for
- Settlement page in the terminal. Date picker defaults to today

### Testing

Checked a handful of dates against the seed data by hand and the numbers look
right. Should line up with the gateway's daily settlement file.
